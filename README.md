# :green_book:File Sorter # 
## ℹ️Описание
Консольный сортировщик файлов. 

   - `sorter.pyw` - сортировщик.
   - `settings_sorter.py` - настройки сортировщика.

### Функционал: 
- Сортировка указанных директорий.
- Игнорирование указанных файлов во время сортировки.
- Логирование действий.

### Особенности:
- Логи и конфиг настроек хранятся по пути `C:\OP_Sorter`.
- Сортировщик создает локальную папку для каждой директории, указанной в настройках, и перемещает туда все файлы во время выполнения процесса.

### Сортируемые расширения:
- **Таблицы:** `.xlsx` `.xls` `.xlsm` `.ods` `.fods` `.cs`
- **Документы:** `.txt` `.docx` `.doc` `.odt` `.rtf` `.pdf`
- **Презентации:** `.pptx` `.ppt` `.odp`
- **Изображения:** `.png` `.jpg` `.jpeg` `.gif` `.svg` `.ico` `.webp`
- **Архивы:** `.zip` `.rar` `.7z` `.gz` `.tar`
- **Медиа:** `.mp3` `.wav` `.mp4` `.mkv` `.mov` `.avi`
- **Код/веб:** `.py` `.pyw` `.json` `.js` `.htm` `.html`
- **Ярлыки:** `.exe` `.lnk` `.url`

## ❓Как запустить
1. Скачайте и установите [**Python**](https://www.python.org/).
2. Скачайте оба скрипта ([**sorter.pyw**](https://github.com/OnePailas/file-sorter/releases/tag/1.0.0), [**settings_sorter.py**](https://github.com/OnePailas/file-sorter/releases/tag/1.0.0)) и перенесите в удобное для Вас место на ПК.
3. Запустите **settings_sorter.py** с помощью cmd или интерпретатора.
4. У Вас откроется меню для настройки сортировщика:
   
      - `1` - Добавить директорию для сортировки.
      - `2` - Добавить игнорируемый файл при сортировке.
      - `3` - Удалить директорию для сортировки.
      - `4` - Удалить игнорируемый файл при сортировке.
      - `5` - Изменить минимальное количество файлов для начала сортировки (На рабочем столе ярлыки не идут в счет).
      - `0` - Сохранить настройки и выйти.

5. Обязательно добавьте директории, которые Вы хотите сортировать. Если не добавить хоть одну директорию, то сортировщик не будет запускаться.
6. Можете закрывать настройки и запускать сортировщик.
